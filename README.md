# Xuewen Luo — Academic Website

A responsive, dependency-free academic portfolio ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The website will appear at `https://YOUR_GITHUB_USERNAME.github.io`.

## Customize

- Edit content in `index.html`.
- Replace the monogram in the `.profile-card` with a portrait when available.
- Replace `assets/Xuewen_Luo_CV.pdf` whenever the CV changes.
- Colors and typography are defined at the top of `assets/style.css`.

No build step is required.
